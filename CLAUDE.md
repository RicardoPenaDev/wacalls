# Contexto para Claude

As instruções canônicas deste projeto estão em `AGENTS.md`. Leia-o inteiro.

Ordem mínima de leitura:

1. `AGENTS.md`;
2. `docs/STATUS.md`;
3. o arquivo da tarefa ativa em `docs/tasks/` e apenas os arquivos de código
   diretamente relacionados.

Não faça varredura completa do repositório sem necessidade. Ao concluir, valide
a entrega (`go build ./cmd/server`, `go test ./...`, `npm --prefix client run
build` quando aplicável) e atualize somente a documentação afetada.
